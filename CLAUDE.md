# CLAUDE.md: bcx-website (bcx.market)

The BCX public website: React and Vite. The source is in `web/`; the built site sits at the repository root, which
GitHub Pages serves as **bcx.market**. Read `README.md` first; it covers the layout, the architecture, the API calls
and the deploy.

## Hard rules

- **A push to `main` is a deploy of the company's live site.** Push only when the owner asks.
- **Edit `web/` only.** The root's `index.html`, `assets/`, `site/`, `CNAME`, `robots.txt` and `.nojekyll` are
  GENERATED by `.github/workflows/build.yml`.
- **This repository is PUBLIC.** No credentials, internal hostnames beyond the public API, or personal data.
  `web/scripts/check.mjs` runs before every build and fails on what it can detect.
- **The newsletter is LOCAL ONLY until the words "deploy newsletter".** Never flip `NEWSLETTER` in
  `web/src/website/flags.js`, and never add `VITE_NEWSLETTER` to an env file for it. A plain "deploy" leaves it off.
- **The site reads `/api/website/*` only**, through `apiUrl()` in `web/src/website/api.js`.
  - Never ULIP, fleet, studio or exchange endpoints.
  - The API is the coal platform's, in GNA's private repo: data and visit-counter changes happen there, and deploy
    there first.
  - That repo's `scratch/dev/_split_website.sh` copies its edited site into `web/`, so until its copy is retired,
    site changes are made there and copied here.
- **No comparison is computed in the browser.** Deltas and periods come from the API payload.
- **A toggle never moves a control.** Panels keep one height whatever is chosen. Measure every new switch.
- **The dark theme is generated.** After editing `web/src/website.css` or `website-bands.css`, run
  `npm run dark-css`. A new chart colour in `charts.jsx` needs its repaint line in `src/website-dark.css`.
- **Phone first.** Check every change at 360, 390 and 430 px as well as the desktop. Nothing scrolls sideways.
- **Every photograph carries its credit** (`web/src/website/media.jsx`).

## Verify before saying done

```bash
cd web && npm run build      # runs scripts/check.mjs first
npm run preview              # then load the pages in a browser, phone and desktop
```
